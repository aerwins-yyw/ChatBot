# ChatBot App

A Python chat bot application powered by OpenAI.

## Setup

1. Clone this repository:
   ```
   git clone https://github.com/aerwins-yyw/ChatBot-App.git
   cd ChatBot-App
   ```

2. Install the required dependencies:
   ```
   pip install -r requirements.txt
   ```

3. Create a file named `openai.env` in the root directory with your OpenAI API key:
   ```
   openai_api_key=your_api_key_here
   ```

4. Run the application:
   ```
   python web_app.py
   ```

## Deploying to Vercel

This app is set up for deployment to Vercel. Follow these steps:

1. Push this repository to GitHub
2. Connect your GitHub account to Vercel
3. Create a new project in Vercel from your GitHub repository
4. Add your OpenAI API key as an environment variable in Vercel
5. Deploy!
